# Checkpoint — minicurso de Next.js

Checkpoint é um catálogo de jogos desenvolvido como projeto didático para um minicurso de Next.js. A proposta é aprender a construir uma aplicação do zero, conectando os conceitos apresentados à prática.

O sistema reúne nove jogos de gêneros variados, com imagens, descrições e páginas de detalhes. Também inclui uma página Sobre e uma seleção de curtidos, com contador no menu e salvamento no navegador.

O projeto utiliza **Next.js, React, TypeScript e CSS**, explorando páginas, layouts, navegação, rotas dinâmicas e estado compartilhado. Os dados dos jogos são locais; os curtidos não exigem conta ou banco de dados.

## O que há neste repositório

- **[checkpoint/](checkpoint/)** — código completo do sistema, com catálogo, detalhes, Sobre e Curtidos.
- **[guia-desenvolvimento/](guia-desenvolvimento/)** — guia prático que orienta a construção do projeto, com tarefas, exemplos de código e explicações dos conceitos.
- **[dowload-recursos.zip](dowload-recursos.zip)** — pacote para distribuir à turma, com CSS, imagens, dados dos jogos e textos com marcação JSX pronta. Não contém o guia nem a aplicação completa: os alunos criam o projeto e desenvolvem sua estrutura e lógica durante a aula.

As imagens e marcas pertencem aos respectivos titulares. Os créditos estão em [fontes.json](checkpoint/public/jogos/fontes.json).
